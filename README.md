# 🧠 Гипноз с нуля

Онлайн-курс гипноза по методике Джерри Кайн (Kayfabe).

**Методика:** Kayfabe (быстрые и мгновенные техники гипноза)

## Структура

```
├── index.html          — Главная
├── modules.html        — Все модули
├── scripts.html        — Библиотека скриптов
├── about.html          — О проекте
├── donate.html         — Поддержать
├── modules/
│   ├── module-0.html   — Введение (бесплатно)
│   ├── module-1.html   — Базовые навыки
│   ├── module-2.html   — Углубление транса
│   ├── module-3.html   — Мгновенные техники ⭐
│   ├── module-4.html   — Феномены
│   ├── module-5.html   — Терапия
│   └── module-6.html   — Продвинутые темы
└── css/
    └── style.css       — Тёмная тема
```

## Технологии

- Статический HTML + CSS
- Тёмная тема, mobile-first
- GitHub Pages (бесплатный хостинг)

## Лицензия

Содержимое курса — на основе методики Kayfabe.
